How Technitium finds answers

In use now

Technitium only sees the devices that use it for DNS. The easy way is to tell your router — then every device on the network uses it.

Point your network at Technitium

DNS server:

  1. In your router's settings, find DHCP or LAN → DNS server, and enter the address above as the only DNS server (a second one would let ads through, and its answers wouldn't know your local names).
  2. Reserve this Synology's address in the router's DHCP settings, so it never changes.
  3. Reconnect a phone or restart a computer so it picks up the change; the numbers on the Blocking tab start to move.
  4. Can't change the router? Set the DNS server on each device instead (Wi-Fi settings → DNS → manual).

Keep DHCP on your router. Technitium has a DHCP server of its own, but the package doesn't open its port.

Encrypted DNS (DoH, DoT)

Lookups from your devices to this Synology stay on your own network, as plain DNS — like with any router. The step that leaves your home, from Technitium to the internet, is encrypted when the Resolvers tab says DNS-over-HTTPS or DNS-over-TLS (the default), or avoided entirely in recursive mode.

Technitium can also serve DNS-over-HTTPS and DNS-over-TLS to devices (Android's Private DNS, for instance), but that needs a domain name with a trusted certificate and more ports open; the package doesn't set it up. Its web console has the settings if you want to.

Technitium's password

For Technitium's own web console (user admin). The package keeps the password it last made, for DSM administrators to see again; if you change it in Technitium's console, make a new one here so the two agree. The package uses an API token of its own, so the window keeps working either way.
